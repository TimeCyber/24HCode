# codeassist_ohos

客户端支持在「定时任务」页面创建重复 prompt。任务保存在本机，首次执行从设定间隔后开始；客户端处于前台并已连接时，每 15 秒检查到期任务并向指定项目发送固定 prompt。应用进入后台时暂停调度，回到前台后处理已到期的任务。
